# Research milestones

## Baseline

Implement analytic geometry, coordinate networks, deterministic sampling, training and independent evaluation. Verify geometry, gradients and extraction diagnostics before interpreting experiments.

## Failure benchmark

Compare thickness and gap sweeps, sampling strategies, independent validation shapes and extraction resolutions. Retain failed trials and separate development from reserved evaluation settings.

## Controlled extension

Evaluate one mechanism against strong ordinary sampling baselines with matched label and compute budgets. Record any extra geometry information and avoid inferring novelty from an implementation alone.

## Validation

Use multiple paired seeds, parameter and storage controls, symmetric surface distances, and resolution-aware topology checks. Report variation, limitations and alternative explanations alongside feature retention.

## Release criteria

- Runnable setup and automated correctness checks.
- At least one measured failure reproduced.
- Fair baseline comparisons, including negative results.
- Clear separation of measured and proposed work.
- Retained protocols, accounting, failures and uncertainty.
